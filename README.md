# Ai — AI Clip Maker

A client-side AI clip maker (in the spirit of Ssemble), named **Ai**. Two ways to work:

1. **YouTube link** — paste a video or channel URL. For a selected video, Ai fetches the source via a
   Piped instance, downloads it into browser storage, analyzes real audio energy + frame motion, builds
   clip candidates, and imports actual YouTube subtitles when available. Export is a real `.mp4`,
   rendered locally by **ffmpeg.wasm**.
2. **Upload your own video** — Ai analyzes audio energy + frame motion, picks the best moments, and
   exports a **real .mp4**: trimmed, centre-cropped to 9:16 / 1:1 / 16:9, captions burned in with your
   chosen style, watermark and procedural music — all rendered locally by **ffmpeg.wasm**.

## Run it

```bash
npm start          # serves on http://localhost:3000
```

No build step and no runtime dependencies — plain HTML/CSS/ES modules behind a tiny Node static server.
For a public GitHub Pages deployment, the `Deploy Ai to GitHub Pages` workflow publishes `public/` from
`arena/c6abac24-ai`. If Pages is not enabled yet, choose **Settings → Pages → Source: GitHub Actions**
in the repository once; the workflow will then publish the site.

## What's inside

| Area | Details |
| --- | --- |
| Landing page | Marketing page with hero rotator, features, how-it-works, sources and an owner-access (no billing) section |
| Access | No login required; each visitor gets a separate local workspace in their browser |
| Dashboard | YouTube video/channel URL **or** drag-&-drop video upload, video type (General/Sports/Game), aspect, caption language, clip count, optional transcript |
| Real analysis | Uploaded and downloaded YouTube sources are scanned per-second: audio RMS loudness + frame-differencing motion → moment scores → non-overlapping clip segments |
| Clip analysis | Source-derived audio/motion scores and clip candidates; hook/description text uses local templates, not a hosted AI model |
| Results | Clip cards with virality ring, preview player, SRT / cover / **MP4** export, multi-select scheduling |
| Editor | Real player (uploaded file or YouTube embed), trim, face-tracking / game-mode toggles, caption list editor, 6 style presets, animations, positions, watermark |
| Real export | ffmpeg.wasm in-browser: cut + crop + scale + burned captions + watermark + music mix → `.mp4` (720p/1080p) |
| Music | Procedural WAV synth (lo-fi, trap, cinematic, phonk, upbeat, ambient, funk) mixed under the original audio |
| Automation | Connect a channel, connected accounts, schedule queue (persisted) |
| Rewards / Analytics / Pricing | Campaigns, canvas charts, plans with credit top-ups |

Projects, clips, queue and settings persist in `localStorage`; uploaded source videos persist in
`IndexedDB`. Nothing is uploaded to a server. This owner-operated copy has unlimited local usage and
no payment processor, subscription gate, or credit top-up flow.

## Notes

- All YouTube/Piped requests and media analysis run in **your browser**. Availability depends on a
  reachable Piped instance, browser CORS support, and the video's format/access restrictions. If
  downloading or decoding fails, retry or attach a local source file; the app reports the failure.
- YouTube clip candidates are created only after real source analysis. If the source has no subtitle
  track and you did not provide a transcript, the app leaves captions empty rather than fabricating
  subtitle text. Hook/description copy uses local templates; it is not generated by a hosted LLM.
- Browsers cannot capture cross-origin YouTube video directly. After the source is downloaded, the
  editor plays that local copy and exports the actual video/audio. Attaching a local copy remains a
  fallback if Piped is unavailable.
- The ffmpeg engine (`public/vendor/ffmpeg/ffmpeg-core.wasm`, ~32 MB) is fetched on first real export.
